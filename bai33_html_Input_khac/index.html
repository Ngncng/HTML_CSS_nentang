HTML5 vẫn còn các loại input sau, tuy nhiên chúng ta sẽ luôn trên tinh thần học và thực hành rồi vỡ kiến thức, không cần thiết phải cố gắng nhớ tất cả nhé. Mình đã hướng dẫn các loại input phổ biến trong form mà thực tế đi làm các bạn sẽ gặp nhiều. Còn danh sách dưới đây chỉ cần tham khảo qua để khi nào cần thì tìm đọc và code nha:
type="url" >>> Định dạng URL.
type="tel" >>> Cho nhập số điện thoại.
type="range" >>> Thanh kéo chọn giá trị.
type="search" >>> Input tìm kiếm.
type="hidden" >>> Input ẩn, không hiển thị với người dùng.
