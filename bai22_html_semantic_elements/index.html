Mục đích của các thẻ HTML Semantic là để cho các trình duyệt, các công cụ tìm kiếm (SEO), công cụ hỗ trợ (như screen reader) sẽ dễ dàng hiểu được cấu trúc nội dung trang web của bạn dựa trên các thẻ Semantic này.

Cấu trúc code rõ ràng (Clean Code) sẽ giúp việc dev, maintain code dễ dàng hơn. Các công cụ tìm kiếm dễ đọc trang web của bạn hơn, từ đó phần nào tăng SEO thứ hạng trang web, rất quan trọng trong việc nhận diện thương hiệu, phát triển kinh doanh. Hỗ trợ accessibility (A11y):Dành cho những người không may mắn bị khiếm thị và phải dùng tới screen reader để có thể hiểu nội dung trên trang web của bạn dễ dàng hơn.
